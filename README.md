# Cryptoplace


A cryptocurrency price-tracking web application built with React.js. The app fetches real-time cryptocurrency data using the CoinGecko API and displays price charts, current prices, market cap, 24-hour price changes, and market rank. It also includes a search bar to search for individual cryptocurrencies.

## Features
- **Real-Time Cryptocurrency Prices**: Displays the latest price of cryptocurrencies.
- **Search Functionality**: Search for specific cryptocurrencies by name or symbol.
- **Price Chart**: Visualize the price trends of cryptocurrencies over time.
- **Market Data**: View market cap, 24-hour price changes, and global ranking of cryptocurrencies.
- **Responsive Design**: Optimized for desktop and mobile devices.

## Tech Stack
- **Frontend**: React.js
- **API**: CoinGecko API
